# Security policy

Please report a vulnerability privately, through
[GitHub's private vulnerability reporting](https://github.com/Dannesk/dannesk-core/security/advisories/new)
for this repository, rather than in a public issue.

Say what you found, how to reproduce it, and the version or commit you used. We will answer in
the advisory, keep you informed while a fix is prepared, and credit you in it unless you would
rather not be named.

Fixes are made on `main` and reach users in the next release of the Dannesk apps.
